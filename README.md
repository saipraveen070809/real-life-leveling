This is a mobile-first Progressive Web App (PWA).

- Exact weekday routine structure
- Saturday: **NO COLLEGE**, but **study is still required**
- Sunday: **exception / recovery day**
- XP rewards and failure penalties
- Level + Stat Points
- INT / STR / CHA / DEX / VIT / WIL
- E → D → C → B → A → S → SS → SSS ranking
- Streaks
- Achievements and titles
- External skill selection
- Weekly Boss
- XP reward shop
- Perfect-day bonus
- 10-minute recovery quest
- Local save on the phone/browser
- Mobile-friendly futuristic system interface

## Install on Android

Because a true APK build environment is not available here, this version is a **PWA** and behaves like an app.

1. Put these files on a web host that supports HTTPS, OR open them through a local/web server.
2. Open `index.html` in Chrome on Android.
3. Use Chrome's **Add to Home screen / Install app** option.
4. Launch it from the home screen like a normal app.

The app stores your progress in browser local storage on the device.

## Saturday rule

Saturday has no college quest. It is still a serious study day:
- Main study block
- AutoCAD / external skill
- Revision / assignments
- Exercise
- Normal night routine

## Sunday rule

Sunday has no daily XP scoring and no failure penalties.
Use it for:
- Weekly revision
- Planning next week
- Light exercise
- Rest / family time


## ⚔ Class & Subclass Progression

- **Level 1–4:** Student / no class
- **Level 5:** Class Awakening becomes available
  - Warrior
  - Scholar
  - Engineer
  - Ranger
- **Level 10:** Subclass specialization becomes available
  - Warrior → Berserker / Guardian
  - Scholar → Strategist / Researcher
  - Engineer → Structural / Construction / Geotechnical / Transportation / Environmental / Water Resources
  - Ranger → Scout / Commander

Class and subclass choices are permanent for the current save and apply stat bonuses immediately.
